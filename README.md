# LogiBIM

**LogiBIM** es un proyecto de innovación orientado a la digitalización y trazabilidad de los procesos logísticos asociados al mobiliario y otros elementos constructivos.

El objetivo es desarrollar una plataforma que permita centralizar y relacionar la información de proyectos, componentes, pedidos, bultos, documentación y operaciones logísticas, facilitando el seguimiento de cada elemento a lo largo de la cadena de suministro.

El proyecto contempla la integración progresiva con la metodología **BIM (Building Information Modeling)** y el estándar abierto **IFC**, permitiendo vincular la información logística con modelos digitales tridimensionales.
